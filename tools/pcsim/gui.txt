# GUI screens: the title screen, the pause menu, the settings screen, the player
# inventory, the containers and the HUD, captured for a side-by-side look.
#
#   MUNT_SIM_SHOTS=/tmp/gui sh tools/pcsim/play.sh tools/pcsim/gui.txt
#
# Containers are opened by using the block under the crosshair, which is the same
# action the left mouse button drives on a desktop. Three details make that
# reliable: the player has to be dropped onto the ground rather than teleported
# into it (a stuck player cannot use a block at all), the crosshair has to be on
# the block, which `aim` sets exactly, and the block is replaced one at a time in
# front of the player so the heading never has to change. On the desktop build a
# container is closed with `t` (the key that opens the player inventory); `shift`
# there would open the pause menu instead.
#
#   aim <yaw> <pitch>   points the camera at a known heading, in degrees

0.0    step 120
0.0    caption The title screen: the panorama, the wordmark with its edition strip, the tilted splash and the vanilla button column.
1.0    shot 01-title

1.4    key space tap
6.0    command gamemode creative
6.1    command time set noon
6.2    command weather clear
6.8    step 33
7.2    caption The HUD with an empty hotbar: hearts, hunger and the hotbar itself.
7.4    shot 02-hud-empty

# A few items in the hotbar, so the icon and the count show up in the widget.
7.6    command give "diamond sword"
7.7    command give planks 64
8.0    command give "iron pickaxe"
8.4    caption The HUD with items: the held item's name above the hotbar.
8.6    shot 03-hud-items

# --- the loading screen ---------------------------------------------------
# Saving draws the loading screen and flushes the buffer itself, because the
# frame's own render fills over it before nglDisplay would have shown it. That
# flush is an SDL_UpdateRect, so a shot queued in the very tick that starts the
# save captures the loading screen rather than the world behind it. "Save World"
# is the fourth entry; the menu came back on "Options..." (the sixth), so two ups
# reach it.
29.8   key up tap
30.4   key up tap
31.5   caption The loading screen: the dirt backdrop, "Loading terrain..." and its progress bar.
31.55  shot 12-loading
31.55  key space tap
32.4   caption Back in the world after saving.
32.6   shot 13-world-saved
33.0   end
