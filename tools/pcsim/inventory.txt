# The player's inventory: the official window, the player model standing in its
# right half, and the three things the window is for -- putting armour on,
# crafting in the 2x2 grid and moving a stack around. Captured for a side-by-side
# look against vanilla.
#
#   MUNT_SIM_SHOTS=/tmp/inv sh tools/pcsim/play.sh tools/pcsim/inventory.txt
#
# The window is the same 176x166 sheet the other containers use, drawn at 2x on
# the desktop, so its slots sit at window-relative source coordinates times two:
# the hotbar starts at (8,142), the storage rows at (8,84), the 2x2 grid at
# (98,18) and its result at (154,28), and the four armour slots down the left at
# (8,8) stepping 18. The mouse is the pointer the model follows: it turns to face
# wherever it is, so the three appearance frames walk it round the player.
#
#   mpos X Y     puts the pointer there, which is what the model and the slots read
#   btn left tap a single left click, which is what moves a stack

0.0    step 120
# Off the title screen into the world, the way every scenario starts.
1.4    key space tap

1.8    command gamemode creative
1.9    command time set noon
2.0    command weather clear
2.2    step 20

# The stacks land in the first free slots, which are the nine on the hotbar.
2.4    command give log 8
2.45   command give planks 32
2.5    command give "iron helmet"
2.55   command give "diamond sword"
2.6    command give cobblestone 64
3.0    step 20

3.6    key t tap

# --- the player model -----------------------------------------------------
# Each of these points the pointer somewhere new; the model turns to follow it,
# the way vanilla's mouse rule turns the player in the window.
4.2    mpos 246 124

4.8    shot 01-inventory-front

5.8    caption The pointer moved to the right, so the player has turned with it.
6.0    shot 02-model-turned-right

7.0    caption The pointer moved up and to the left: the player has turned the other way and leaned back to keep looking at it.
7.2    shot 03-model-turned-left

# --- equipping armour -----------------------------------------------------
# The helmet is the third stack, in the hotbar's third slot. Picking it up and
