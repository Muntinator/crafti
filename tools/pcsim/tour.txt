# Muntcraft autoplay tour.
#
# Run it with `sh tools/pcsim/play.sh`. Times are seconds of *game* time, so the
# tour reads the same however fast the machine renders; `step` is how much game
# time one frame carries, and it is raised while waiting and lowered while
# moving, because motion clips want smooth frames and waiting does not.
#
# Lines are:  <time> <command> [args]
#
#   step <ms>            game time per frame
#   key <name> down|up|tap
#   type <text>          types text, one character every other frame
#   look <dx> <dy> [n]   per-frame mouse look rate, in pixels (3 px = 1 degree),
#                        held for n frames and then let go -- which is how a turn
#                        of a known number of degrees is asked for
#   btn left|right down|up|tap
#   caption <text>       what the gallery says about the captures that follow
#   shot <label>         capture one frame
#   clip <label> <n> [stride]   capture n frames, one every stride
#   command <line>       run a console command through runCommand() directly
#   probe [text] / scan [r]     print the game's state / a height map
#   echo <text>          a marker in the run log
#   end
#
# Console commands go through `command`, not through typing: runCommand() is the
# same entry point the console uses, so the reply lands in the run log and no
# keystroke can be dropped. One command is still typed at the end, on camera, to
# show the console itself.
#
# Key names: esc tab enter space del ctrl shift, the arrows, and single
# characters for the letters, digits and punctuation keys.
#
# Desktop bindings this tour relies on (task.cpp): w/a/s/d move, space jumps,
# t opens the inventory, tab the menu, r or . the block list, / the console,
# 1 and 3 step the hotbar, e and q are the two mouse buttons.

0.0    step 120
0.0    caption The loading screen: Muntcraft's own splash bitmap, drawn through nGL.
0.0    shot 01-loading
1.0    caption The title screen, over the pre-rendered 1.17 panorama.
1.0    shot 02-title

# --- a new terrain world --------------------------------------------------
1.4    echo starting a new terrain world
1.4    key space tap
6.0    command gamemode creative
6.1    command time set noon
6.2    command weather clear
6.4    probe spawned
6.5    scan 5

# --- the world ------------------------------------------------------------
7.0    step 33
7.0    caption A freshly generated seed at noon: a sandy shore, dunes rising away from the water behind the spawn point. The terrain, the sky and the sea are all drawn by the game itself, through nGL.
7.6    shot 03-world-noon
8.0    probe at spawn

# A full turn on the spot. 27 captures every 5th frame is 135 frames, and 135
# frames of 8 px of mouse per frame is exactly one 360 degree turn.
8.2    echo --- panorama: a full turn on the spot
8.2    caption The panorama clip: one full turn from the spawn point, played as an animation by the gallery.
8.2    look 8 0 135
8.2    clip 04-panorama 27 5
13.4   caption The horizon at the end of the turn, with the sea behind the dunes.
13.6   shot 05-horizon
13.9   probe after the turn

# Walk forward into the world.
14.5   echo --- walking
14.5   caption Walking forward: the camera bobs and the terrain scrolls past. This is the second clip the gallery plays.
14.5   key w down
14.6   clip 06-walk 16 4
16.9   caption Standing still again: the walk ended on the slope above the shore.
17.0   key w up
17.2   shot 07-after-walk
17.4   probe after walking

19.2   command setblock 3 16 4 "gold block"

19.8   command setblock 2 16 2 bed 8

22.6   probe built

23.4   key t tap
