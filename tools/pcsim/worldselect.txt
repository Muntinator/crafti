# The "Select World" screen, captured with its interactions: the world list, the
# keyboard, the search filter, the hover overlay, and the three dialogs vanilla
# opens from it -- Edit, Delete and Create New World.
#
#   MUNT_SIM_SHOTS=/tmp/worldselect sh tools/pcsim/play.sh tools/pcsim/worldselect.txt
#
# The screen is vanilla's WorldSelectionScreen: a "Select World" heading at y 8,
# the search box at y 22, the list from y 48 down to height - 64 with 36-pixel
# rows (a 32x32 icon and the name over two grey detail lines), and vanilla's two
# button rows at height - 52 and height - 28. The desktop harness runs at twice
# the GUI scale, so every number below is the calculator's doubled.
#
#   mpos X Y     puts the pointer there, which is what hover tests against
#   btn left tap click; "key s tap" is the down arrow; letters type into the
#   search box, and "key backspace tap" deletes
#
# The run starts with no saved world, so the list offers the engine's world
# kinds as rows and nothing is greyed out. Key taps are half a second apart: a
# tap lasts one frame, and two of them landing in the same frame would read as
# one held key.
