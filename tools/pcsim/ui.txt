# The UI screens this pass restyled: the graphing screen, the help screen, the
# block list, the sound test, the command console and the death screen.
#
#   MUNT_SIM_SHOTS=/tmp/ui sh tools/pcsim/play.sh tools/pcsim/ui.txt
#
# The world is started from the title screen the same way
# tools/pcsim/gui.txt does it (space picks the default entry), and the pause menu
# is the hub between the screens: each one is reached by moving the selection
# down from "Back to Game" and pressing space, exactly as a player would. The
# pause menu opens each screen as a child, as vanilla does, so closing one comes
# back to the pause menu (keeping the button that opened it focused, as vanilla's
# screens do) rather than dropping the player into the world. Because the
# selection is kept, each following screen is one step further round the grid,
# not reached from "Back to Game" again.
#
# The pause grid is vanilla's, in vanilla's order: Back to Game / Help, Block
# List / Save World, Sound Test... / Options..., Player Inventory / Save and Quit
# to Title -- so Help is one down, Block List two, Sound Test four.
#
#   s = down, space = select / space = enter the world, slash = open the console
#   hurt N = deal N damage straight through WorldTask::hurtPlayer
#
# The block list is the vanilla creative inventory: its three pages are the three
# tabs, so 7/9 step between them (e/q on the desktop harness), and a page longer
# than the 9x5 grid scrolls with 2/8 (s/w or the arrows), moving the scrollbar
# handle the way the item list does.

0.0    step 120
0.0    caption The title screen, for reference.
1.0    shot 01-title

# --- Graphing Mode is one step below the opening selection ---------------
# The title opens on "New Terrain World" (a fresh world has no "Continue"),
# so one down reaches the entry above it, "Graphing Mode".
1.4    key s tap
1.8    key space tap
2.6    caption Graphing Mode: the vanilla dirt backdrop, a heading, and the expression field drawn as a vanilla text field (a black box in a light border).
2.8    shot 02-graph
3.4    key esc tap

# --- start a world --------------------------------------------------------
4.6    key space tap
8.2    command gamemode creative
8.3    command time set noon
8.4    command weather clear
8.8    step 40
9.2    caption Back in the world.

# --- the help screen ------------------------------------------------------
10.4   key esc tap
11.2   key s tap
11.6   key space tap
12.4   caption The help screen: the same dirt every vanilla menu sits on, a centred heading and the control list.
12.6   shot 03-help
# Closing Help returns to the pause menu, as it does in vanilla. The menu keeps
# the selection, so it comes back on "Help"; one more down reaches "Block List".
13.2   key esc tap

# --- the block list -------------------------------------------------------
14.0   key s tap
14.4   key space tap
15.6   caption The block list: the vanilla creative inventory -- the official 195x136 window with its 9x5 slot grid and hotbar, the three tabs across the top with the selected one lit, the cursor frame on the held entry, and the scrollbar beside the grid.
15.8   shot 04-blocklist
# The tabs are the pages; 9 steps forward to the second tab, "Items" (q here).
17.0   key q tap
17.8   caption The second tab, "Items": the same window, with the "Items" tab lit and the grid holding tools and materials -- a tab is a page, so switching pages is switching tabs.
18.0   shot 05-blocklist-items
# Back to the first tab, then scroll it past the fifth row by walking the cursor
# down, so the grid follows the selection and the scrollbar handle travels.
18.6   key e tap
19.0   key s tap
19.4   key s tap
19.8   key s tap
20.2   key s tap
20.6   key s tap
21.0   key s tap
21.6   caption The first tab scrolled to its last row: the grid has stepped down a row at a time and the scrollbar handle has travelled to the bottom of its track, exactly as the creative item list does when the cursor leaves the visible rows.
21.8   shot 06-blocklist-scrolled
22.4   key esc tap

# --- the sound test -------------------------------------------------------
# Back at the pause menu, still on "Block List"; "Sound Test..." is the fifth
# entry, so two downs reach it from there.
23.0   key s tap
23.4   key s tap
23.8   key space tap
25.4   caption The sound test: the official widget button in its plain and highlighted states, over the vanilla backdrop.
25.6   shot 07-audiotest
26.2   key esc tap

# --- the command console --------------------------------------------------
26.8   caption Back at the pause menu.
27.0   key esc tap
27.8   key slash tap
28.6   type weather
30.2   caption The command console: a vanilla chat-style translucent panel over the world, with the prompt and the command hints.
30.4   shot 08-console
31.0   key esc tap

# --- the death screen -----------------------------------------------------
31.6   command gamemode survival
32.4   step 40
32.8   command time set noon
33.6   hurt 20
34.6   caption The death screen: vanilla's red fade, the doubled "You Died!" title, the respawn line, and vanilla's "Score: 0" -- a world with no scoreboard starts at zero, exactly as vanilla's does.
34.8   shot 09-death
35.2   key space tap
36.0   caption Respawned at the world spawn.

# Set a score and die again, so the capture shows the line tracking the player's
# own score -- not experience, which is a separate total.
36.4   command score 7
37.0   step 40
37.4   hurt 20
38.4   caption The death screen again, now with a score set: vanilla shows the player's score on this line.
38.6   shot 10-death-score
39.2   end
